# Asset provenance

## Runtime
- Original procedural car, track, scenery and game graphics: created for this project, with editable source in `src/game/`.
- Asphalt Track, Sparse Grass, Sundowner Overlook HDR: Poly Haven CC0; runtime sources recorded in public/assets/NOTICE.txt. Generated foliage atlas: OpenAI image generation. Original car: editable Blender script in scripts/build_car.py; mesh exported as public/assets/models/astra-formula.glb. Superseded cracked asphalt maps removed from the shipping assets.
